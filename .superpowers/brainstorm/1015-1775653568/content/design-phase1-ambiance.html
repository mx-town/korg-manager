Phase 1 Design — Section 3: Idle Ambiance

The app breathes when you're not touching it

The Concept

Real hardware doesn't sit perfectly still. LEDs flicker imperceptibly. Displays have a faint refresh shimmer. Power indicators glow with slight warmth variation. The app should feel alive — like it's powered on and waiting, not frozen in a screenshot.

Ambiance Layers

Layer 1: LED Flicker

Where: Active part indicators, sidebar device icons, power/status LEDs
How: led-flicker with staggered delays (no two LEDs sync). Opacity oscillates 0.85↔1.0 over 3-5s. Barely noticeable — felt more than seen.

Layer 2: Glow Breathing

Where: Selected pattern card border, active tab underline, waveform container border
How: glow-pulse on box-shadow. Very slow (5-8s cycle). The selected/active element gently pulses its glow as if power is flowing through it.

Layer 3: Scan Line Drift

Where: Waveform display background, pattern grid background (subtle)
How: A single 1px bright line drifts top→bottom over 8-10s. Very faint. Evokes CRT monitor feel. CSS-only via translateY animation on a pseudo-element.

Layer 4: Header Pulse

Where: The 3px pink border at the bottom of the header bar
How: Gradient position shifts slowly left↔right. The "power line" along the top of the app gently shimmers. Like electricity flowing through a circuit trace.

Performance Rules

CSS only

No JS animation loops. All ambiance is pure CSS @keyframes + transitions. Zero main-thread cost.

opacity + transform

Only animate compositor-friendly properties. No layout triggers. No repaints on box-shadow (use pseudo-elements for glow).

prefers-reduced-motion

All ambiance respects @media (prefers-reduced-motion: reduce). Turns off all idle animations.
