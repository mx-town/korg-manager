Phase 1 Design — Section 2: View-by-View Polish

Bringing every view up to PARTS-level quality

STEPS View

Current

Flat fill, uniform border, no depth distinction between on/off. Feels like a wireframe.

Proposed

Gradient fill, LED glow on active steps, inset highlights for depth. OFF steps feel like recessed rubber pads.

Changes: OFF steps get hw-panel gradient + inset shadows (rubber pad feel). ON steps get gradient fill (bright→dark of their color) + outer glow + inset top highlight (lit LED cap). Velocity drives glow intensity. 4-beat markers get subtle vertical accent lines like GRID already has.

GRID View

Current (already decent)

Beveled borders are solid hardware-feel. ON cells use currentColor glow. But: part names column is unstyled, row headers have no depth, no velocity visualization beyond color.

Proposed enhancements
  • Part name column: hw-panel gradient + type-colored left accent border
  • Row hover: subtle horizontal highlight strip across all 128 cells
  • ON cells: add inset top highlight (the "lit LED cap" look)
  • Velocity → glow radius mapping (low vel = tight glow, high vel = wide bloom)
  • Muted rows: scanline overlay + desaturate, not just opacity

E2S Sampler

The E2S view is the furthest behind — it's functional but looks like a prototype next to the ESX manager. The fix:

  • Toolbar: Match ESX header style — hw-panel gradient background, bottom border glow
  • Sample list: Adopt ESX's row styling (selected glow, hover lift, category color accents)
  • Controls panel: Category dropdown, tune slider, loop type — all get hw-panel treatment with focus glows
  • Waveform: Already shared with ESX — no changes needed
  • Memory bar: Add the same fill animation + gradient that ESX uses

Pattern List / Selector

  • Pattern cards: hw-panel gradient with device-colored left accent (pink=ESX, blue=EMX, cyan=E2S)
  • Selected pattern: Brighter gradient + color glow halo + inset scanline texture
  • Empty patterns: Very dim with subtle crosshatch overlay (like unused hardware slots)
  • Search field: LCD-style input with cyan text-shadow, focus glow ring
