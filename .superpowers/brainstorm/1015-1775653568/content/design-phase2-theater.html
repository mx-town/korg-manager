Phase 2 Design — Theatrical Moments

The 5 moments that make people say "holy shit"

1. Boot Sequence

First impression = everything

T+0ms
Screen is black. 200ms of nothing. Anticipation.
T+200
ELECTRIBE SAMPLE WERKSTATT
Logo fades in with warm-up animation (cold blue → warm pink). Text-shadow blooms outward.
T+800
System check LEDs light up left→right. Each one "pops" on with a tiny scale overshoot.
T+1200
SYS PARSERS OK   MEM 26.5MB FREE   VER 1.0.0-beta.1
System readout types in character-by-character (typewriter effect). Shows real values from get-version/get-state IPC.
T+1800
Header power line sweeps in. Sidebar slides in from left. Main panel fades up. Ambiance begins.
T+2200
READY
Full UI visible. Total boot: ~2.2 seconds. Fast enough to not annoy, slow enough to impress.

Implementation: CSS overlay with @keyframes choreography. System readout calls real IPC handlers (get-version, get-features). Runs once per app launch. Skip with Escape key or click. localStorage flag to disable permanently via settings.

2. Waveform Theater

Samples come alive visually

Playback Glow

During audio playback, the waveform canvas gets a subtle animated glow border that pulses with the playhead position. The cursor line emits a soft bloom. When it reaches a peak in the waveform, the glow intensifies briefly.

Hover Reveal

Hovering over the waveform shows a vertical "scan line" at cursor position. Tooltip displays time position + sample value. The waveform area directly under the cursor brightens slightly — like a spotlight following your mouse.

Import Animation

When a new sample is imported, the waveform doesn't just appear — it "draws in" left→right over 300ms, as if being recorded onto tape. Peak/RMS analysis numbers count up from 0 to their final value.

FX Preview

In the Modify modal, when you adjust an FX slider, the waveform preview updates in real-time with a "ghost" overlay showing the before/after. The ghost is a dimmer copy of the original that fades as you commit.

3. Pattern Playback Light Show

The step grid becomes a live performance display

Step 1 is the current playhead — brighter glow + cyan outline. Other ON steps glow at their velocity level.

Playhead March

Current step gets boosted glow + cyan outline (already exists). New: a faint "trail" — the 2 steps behind the playhead keep a dimming afterglow. Creates sense of motion direction.

Velocity Bloom

When the playhead hits an ON step, the glow flares momentarily — bigger bloom for higher velocity. Like the LED is being struck. Decays over 150ms back to resting glow.

Part Color Rows

In GRID view, each part row uses its type color for ON cells. During playback, the active column gets a vertical highlight strip across all rows — a "now line" that sweeps across the grid.

Beat Pulse

On every downbeat (step 1, 5, 9, 13), the transport PLAY button glow flares. BPM display briefly brightens. The header power line pulses. The whole UI "breathes" with the tempo.

4. Import/Export Spectacle

File operations become visual events

Sample Import
LOADING SAMPLES... 13/20

Batch imports show a VU-meter style progress bar (gradient cyan→green). Each sample "lands" in the list with a brief flash. Counter ticks up. On complete: all new samples do a quick cascade glow top→bottom.

File Save / Export
WRITING 26,542,080 BYTES COMPLETE

Save/export shows the existing diagonal stripe animation (already built!) but enhanced: real byte count displayed, pink→green color shift on completion, brief "SAVED" flash in the header. The stripes use the existing expAnim keyframe.

5. Waveform Idle Ambiance

The waveform display is never truly still

When a sample is loaded but not playing, the waveform display shows subtle life:

  • Scan line: The Phase 1 scan-line-drift runs across the waveform background
  • Border glow: The waveform container border gently breathes with glow-pulse
  • Peak markers: The highest peaks in the waveform get tiny dot indicators that flicker with led-flicker
  • No sample loaded: Empty state shows a flat line with slow noise animation — like a powered-on oscilloscope with no input signal
